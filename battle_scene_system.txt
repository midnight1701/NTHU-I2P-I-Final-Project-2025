Battle system/scene
1. Enter for the first time: Set up player & enemy's monster, with player's monster drawn on screen first, after player has entered the key "space"
- When enter, a dialogue will be displayed immediately: "Enemy trainer challenges you to battle"
- For dialogue, a dialogue pg.rect must be initialized as the standard placeholder for dialogues


- Dialogue system: Display player's choices, actions
- Types of dialogue: Announcement: announce the current actions, Selection: provide users with options (attack, flee, defend,...)
--> Dialogue system - Implemented using function(s)
+ In the dialogue, for each turn, the system will check if player's key input is K_SPACE (for announcement dialogue)

+ For setup phase, dialogue system only outputs announcement dialogues
+ In the setup phase, enemy's monster is displayed first
+ After player's input(K_SPACE), player's monster is displayed, and setup phase is complete
+ After setup phase, player and enemy's monsters are always displayed, meaning in the update function of the battle scene, player and enemy's monster must always be drawn (unless changes are made)


- Announcement dialogues:
+ Display the name of enemy's monster & player's monster
+ Display the damage player/enemy inflicts upon one's opponent


Battle sequence:
- If player's turn:
+ Check if player is alive
+ Get action --> Display options on screen
+ Check for action --> After player has clicked 1 of the 4 options
+ Perform action --> Perform selected actions + Display dialogue
+ Display result of the action --> Change to displayed info (HP, state..)

State:
- K_Space --> Change dialogue
- Player turn: Choose action --> Display dialogue (without K_Space)
- Perform action --> Display dialogue (when K_Space is detected)
- Enemy turn: Choose action (random) --> Display dialogue (when K_Space is detected)


Dialogue
- Setup: 
+ "Enemy trainer challenges player to a monster battle"
-- Space
+ "Enemy trainer selects {monster_name}"
-- Space
+ "Ally trainer selects {monster_name}"
-- Space

- Battle:
1. Player turn
- What will ally trainer do (+ display options)
- Trainer select --> Display action dialogue (without dialogue)
- Display result of the action (attack, defend, run, potion) (when K_Space is detected)
- Check if enemy is alive --> If enemy is alive --> Change turn --> Display "What will enemy trainer do" (when K_Space is detected)

2. Enemy turn
- "What will enemy trainer do" (from previous) --> Random selection --> Display action (when K_Space is detected)
- Display the result of the action (when K_Space is detected)
- Check if ally is alive --> If ally is alive --> Change turn --> Display "What will ally trainer do"
